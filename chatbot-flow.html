Lógica interna

Motor de matching por puntaje
Para cada intención, suma la longitud de todos los patrones que coincidan en el input normalizado. Gana la intención con mayor puntaje. Esto evita falsos positivos por patrones cortos.
Anti-repetición
Si el usuario pregunta lo mismo dos veces seguidas, el bot descarta la última respuesta usada y elige una diferente del mismo tema (cuando hay más de una respuesta disponible).
Normalización de texto
Todo input pasa por: minúsculas → quitar tildes (NFD) → quitar caracteres especiales → trim. Así "¿Quién es BRUNO?" y "quien es bruno" son equivalentes.
